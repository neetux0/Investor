# 90日行動計画（2026-09-19 〜 2026-12-17）v2

v1（9/18）に対し、本人回答8項目を反映して数字と手順を差し替えた。

## 結論
- 基準3億の必要年率は 35.3%（v1の27.5%から上昇）。原因は、流入が技能ゼロで当面月3万止まりであること、2035年4月以降に生活費が発生することの2点。達成確率は 基準3億 2% / 挑戦7.5億 0.7% / 最大35億 0.1%。
- 3億の分岐点は「勝負枠で年率+30%を15年」。+20%だと5,500万で止まる。したがって90日の目的は、勝負枠の戦略が+30%圏を狙える型かどうかを実弾30件で判定すること。
- 最大のレバーは投資でも労働でもなく、**Pythonでの検証技術**。これが投資の精度と、唯一の売れる制作物の両方を作る。90日で着手する。

### 暗号資産を勝負枠の20%上限にする理由
| 項目 | 日本株（特定口座源泉徴収あり） | 暗号資産 |
|---|---|---|
| 税率 | 20.315% 分離課税 | 雑所得 総合課税（父の扶養内なら実質 5〜15%だが、扶養を外れると父の税負担が増える） |
| 扶養への影響 | なし | 実現益が基礎控除を超えると確定申告が必要になり、扶養判定の所得に入る |
| 損失の繰越 | 3年可 | 不可 |
| レバレッジ | 信用 約3.3倍 | 国内取引所 2倍 |

暗号資産の分離課税化が法制化された時点で上限を見直す。それまでは「日本株の戦略が暗号資産でも通用するか」を試す枠として使う。

## 90日の構成

### 第1期 セットアップ（第1〜2週、9/19〜10/2）
- マネックスに100万入金。特定口座は源泉徴収あり。
- 楽天証券でNISA勘定廃止届を提出し、勘定廃止通知書を受け取る（総合口座の解約はこの後）。
- 10/1以降、マネックスでNISA口座開設（2027年分）を申請し、通知書を添付。
- 中核30万を特定口座で全世界株投信に一括買付。
- **過去3年の売買を全件 `journal/取引記録.csv` に書き出す。** 通算プラスの中身（何で勝ち、何で負けたか）が戦略候補を決める。
- 戦略候補: 過去の売買で勝ち筋があればそれをAにする。なければ以下。
  - A: 決算後ドリフト。上方修正・好決算の翌日寄り買い、5〜10営業日で手仕舞い。
  - B: 出来高急増ブレイク。グロース・スタンダードの出来高5倍以上の高値更新を買い、直近安値割れで撤退。
- 各戦略の過去サンプルを手作業で50件以上取り、勝率・平均損益・最大DDを出す。
- 暗号資産口座（国内取引所1社）を開設。入金は14万まで。

### 第2期 ペーパー検証（第3〜4週、10/3〜10/16）
- 2戦略を同時にペーパー。ルールは書面化、裁量なし。
- 第4週末に1本に絞る。基準: ペーパー10件以上で期待値プラス、ルール遵守率80%以上。
- 両方ダメなら2週延長。実弾に進まない。

### 第3期 小ロット実弾（第5〜13週、10/17〜12/17）
- 1トレードの最大損失 = 勝負枠の2%（1.4万円）。ロットは損切り幅から逆算。
- 同時保有3銘柄まで。月間DD 10%（7万）で当月の新規建て停止。
- 暗号資産は日本株で採用した戦略をそのまま適用。日本株と別の戦略は試さない。
- 90日終了時に実弾30件到達を目標。未達なら期間延長、ロットは上げない。

### 技能習得と流入（並行、週6時間）
技能ゼロのため、労働で稼ぐより「投資に直結する技能を作って売る」に切り替える。

| 週 | 内容 | 流入目標 |
|---|---|---|
| 1〜2 | セルフバック（ASP経由の証券・暗号資産口座開設、クレカ発行）。一時収入 | 累計 3〜5万 |
| 1〜13 | Python基礎 → 株価データ取得 → 自分の戦略のバックテスト。教材は無料のもの（公式チュートリアル、Qiita、GitHub）で足りる | 0 |
| 3〜13 | クラウドソーシングのタスク案件（データ入力・文字起こし）。時給換算300〜500円だが評価を作る目的 | 月1万 |
| 13 | 自作バックテストのコードと検証結果をGitHubで公開。次の90日で有料化を判断 | 0 |

90日の流入目標: 累計6万円。月10万に乗るのは2028年以降と見ている。

## 90日終了時の判定
- 合格: 実弾30件以上、期待値プラス、最大DD 15%以内、ルール遵守率80%以上。次の90日で信用取引を解禁し、Python検証で戦略を2本目に増やす。
- 不合格: いずれか未達。ロット半分で90日延長。3回連続不合格なら勝負枠を中核に移し、戦略を根本から作り直す。
- 純資産の見込み: 100万 + 流入6万 ± 勝負枠（-18万〜+12万）。90日で増えることは期待しない。

## 2035年問題
実家退去は8年半後。その時点で純資産が3億ルート上（約4,000万）なら、年7%の中核運用だけで生活費を賄える。ルート上にいなければ、退去時点で流入源が月10万必要。Python技能はこのための保険でもある。
